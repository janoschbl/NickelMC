Expand description

A mob’s memory-driven AI.

Mirrors vanilla Brain. The schedule is not stored here: the mob passes the activity its schedule asks for to update_activity_from_schedule.

fn start_each_non_running_behavior( &mut self, mob: &dyn Entity, level: &Arc<World>, )

Starts every stopped behavior of an active activity, lowest priority first.

The active activities are read live, so a behavior that switches activity affects the groups that follow it.

Source

fn tick_each_running_behavior(&mut self, mob: &dyn Entity, level: &Arc<World>)

Ticks every running behavior, whatever activity it belongs to.

A behavior that started under an activity the brain has since left keeps running until it times out or gives up. Switching activity erases that activity’s memories instead of cutting its behaviors off mid-run.
