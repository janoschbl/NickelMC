Expand description

A view to the synced data of a Display.

This trait has common methods, for all displays, to access and modify data specific to display entities. Use Display::with_view to access a view for an entity.

fn set_transformation_interpolation_delay(&mut self, duration: i32)

Sets the display entity’s start interpolation delay (the delay in starting an interpolation), in ticks, to duration, and restarts the transformation animation (regardless of what duration is).

If this is set to 0, interpolation starts immediately.

Note: This property is not saved to disk.
